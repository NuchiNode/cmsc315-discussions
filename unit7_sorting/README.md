This assignment helped with understanding the difference between Bubble Sort and Merge Sort and how both can sort the 
same data using different methods. Bubble Sort was easier to understand because it compares values next to each 
other and swaps them when they are out of order. Merge Sort took longer to understand because it uses 
recursion to keep breaking the list into smaller parts before merging everything back together. Recursion logic is 
something that I am still practicing and learning. 

One issue I ran into was understanding how the left and right indexes move through the lists during the merge process. I
also had an indentation error inside the while loop, which caused the program not to run. Fixing the indentation and 
testing with smaller datasets helped me understand what the code was doing.

Bubble Sort has O(n^2) time complexity and would be better for smaller datasets where performance is not a major concern.
Merge Sort has O(n log n) time complexity and would be better for larger datasets. The tradeoff is that Merge Sort is 
more efficient, but it is also more complex and uses additional memory.
